# Mini shop

Необходимо реализовать небольшое SPA интернет-магазина на React + TypeScript. Для получения данных о товарах использовать открытый API: <https://dummyjson.com/docs/products>. Ориентировочное время выполнения: 3-4 часа.

## Что необходимо сделать

### 1. Список товаров

- Получить товары с API и отобразить их в виде списка/сетки.
- Для товара показать название, цену и изображение.
- Добавить поиск по названию.

### 2. Корзина

- Пользователь должен иметь возможность: добавить товар в корзину; изменить количество товара; удалить товар из корзины.
- В шапке приложения отображать количество товаров в корзине.

### 3. Избранное

- Пользователь должен иметь возможность добавлять и удалять товары из избранного.
- Сделать отдельный раздел/экран со списком избранных товаров.

### 4. Состояние приложения

- Корзина и избранное должны быть доступны из разных частей приложения. Например, товар можно добавить в корзину из списка товаров, после чего его количество должно сразу обновиться в корзине и в индикаторе корзины в шапке.
- При переходе между разделами приложения состояние корзины и избранного не должно сбрасываться.
- После перезагрузки страницы корзина и избранное также должны сохраняться.

### 5. Состояния интерфейса

- Предусмотреть: состояние загрузки; обработку ошибки загрузки; пустой список товаров; пустую корзину; пустой список избранного.

## Требования

- React + TypeScript.
- Использовать функциональные компоненты и hooks.
- Для работы с API можно использовать fetch или любую подходящую библиотеку.
- Библиотеки для управления состоянием можно выбирать самостоятельно.
- UI-библиотеки - по желанию. Не требуется делать сложный дизайн - важнее структура приложения и корректная работа.
- Будет плюсом: аккуратная структура компонентов; отсутствие лишнего дублирования состояния; хорошая обработка асинхронных операций; понятный и поддерживаемый код.
